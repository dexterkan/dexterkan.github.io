01 / THE DETECTION PROBLEM

One received signal. Many candidate symbol vectors.

The receiver observes y′ = Hx + w and must recover a discrete transmitted symbol vector. Maximum likelihood (ML) minimizes the squared residual; its candidate space grows exponentially with transmit antennas and modulation order.

Turn detection into sequential decisions

QR decomposition converts the objective to ‖y − Rx‖². The triangular structure allows symbols to be decided from the last coordinate backward. Each tree node represents a partial symbol vector; each edge chooses one PAM symbol.

A 2 × 2 QPSK example has four real-valued decisions with two possible actions each. The complete candidate space contains 16 leaves.

Learn from the detection metric

The agent’s state includes received-signal representations, current and previous partial estimates, and incremental and accumulated detection metrics. Its reward is the negative accumulated squared residual.

Rewards use the received vector, channel information, and candidate estimate, avoiding a requirement for transmitted-symbol or exhaustive ML labels in the loss calculation.

02 / NEURAL GUIDANCE MEETS TREE SEARCH

A policy chooses promising moves. A value estimates their outcome.

Three networks, two inference outputs

The actor outputs a probability distribution over symbol choices. A critic trains the actor through temporal-difference feedback and is used only during training. A separate state value network takes the state plus policy output and predicts the final negative detection metric.

Each network has six fully connected hidden layers. The actor ends in softmax; the critic and state value network output scalars (Table I).

What changes from MCTS?

Ordinary MCTS estimates outcomes by randomly completing a symbol vector. DRL-MCTS replaces that rollout with a learned value and weights exploration using learned action priors.

03 / EXPLORE THE EVIDENCE

Compare detection quality and search budget.

Select an antenna/modulation configuration and compare the original symbol error rate (SER) plots. Lower SER is better; transmit × receive antenna counts follow the paper’s notation.

DRL-MCTS improves SER over standalone DRL and MCTS in the reported sweep.

Search and learning complement each other.

The actor alone is fast but omits both search exploration and state-value estimates. Random-rollout MCTS searches without neural guidance. Combining them improves detection in these experiments, while still taking more time than feed-forward or linear detectors.

05 / TRAINING & EVALUATION SCOPE

Self-generated experience, evaluated on separate signals.

Training pipeline

Up to 12 agents interact with their own environments, generate detection trajectories, and compute local gradients. Their combined gradients update a global network; updated parameters are sent back to the agents. RMSProp starts at a learning rate of 10⁻⁴, with discount factor 0.95.

The policy uses actor-critic feedback and an entropy term for exploration. The state value network learns from the final detection metric rather than an exhaustive ML label.

What the evidence covers

The experiments use uncoded 8 × 8 BPSK, 8 × 8 QPSK, and 8 × 16 QPSK under a varying-channel model. Test signals are generated separately from training. Channel variation ε is 0.10 for BPSK and 0.08 for QPSK.

The receiver assumes known channel information. These are numerical experiments, with no demonstrated radio deployment, universal channel generalization, or guarantee that finite-budget DRL-MCTS returns the ML optimum.
